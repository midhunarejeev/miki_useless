### Project Description
A cute digital mosquito that flies around your screen, taunts your reflexes, dodges your clicks with quantum evasion physics, buzzes into your headphones with 3D procedural audio, and completely obliterates human workplace productivity.

### The Problem (that doesn't exist)
Workers and students worldwide are suffering from dangerous levels of focus, uninterrupted productivity, and alarming peace of mind. Computers have become overly obedient machines that do what users click without ever buzzing right past their ears or mocking their motor skills.

### The Solution (that nobody asked for)
**Digital Mosquito 2.0**: An intentionally evasive, cute digital mosquito mascot named **Mozzy 2.0**.
- Whenever you attempt to click or swat it, it calculates your cursor threat vector and dodges away with cheeky taunts.
- Missing clicks escalates the **Irritation Meter**, triggering high-speed zig-zags, quantum teleportation, decoy ghost swarms, screen-shake rage, and itchy digital bite bumps.
- Equipped with procedural 3D binaural buzzing that pans between your headphones, plus 4 swat weapons: The Legendary Chappal (🩴), Neon Bug Zapper (⚡), Rolled Newspaper (📰), and Bare Hand (🖐️).

## Technical Details

### Technologies / Components Used
For Software:
- **Languages**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Styling**: Tailwind CSS (CDN), Custom Glassmorphism, CSS 3D Keyframe transforms
- **Audio Synthesis**: Web Audio API (Zero external audio files — 100% procedural Sawtooth/Sine FM oscillator with StereoPannerNode and dynamic Doppler effect)
- **Graphics & FX**: Custom Vector SVG Mosquito Mascot, HTML5 Canvas Particle Engine (confetti, smoke puffs, electric sparks)
- **Typography & Icons**: Google Fonts (`Outfit`, `Fredoka`, `Space Grotesk`), FontAwesome 6

## Implementation

### Installation
No heavy installs or complex node modules required. Simply clone the repository:
```bash
git clone https://github.com/midhunarejeev/The_unemployed_coders_useless.git
```

### Run
Open `index.html` (or `demo.html`) directly in any modern web browser:
```bash
# On Windows PowerShell:
Start-Process index.html

# Or via any local server (e.g. VS Code Live Server / Python):
python -m http.server 8000
```

## Features & Highlights

1. **Procedural 3D Ear-Invader Audio**:
   - Synthesizes 450Hz mosquito wing buzzing in real-time.
   - Spatial panning follows the mosquito horizontally across your speakers.
   - Frequency flutters with wing speed and irritation level.

2. **Quantum Evasion AI Engine**:
   - Monitors cursor coordinates at 60–120Hz.
   - Within proximity, calculates threat vectors and dashes away.
   - Escalates from gentle floating to zig-zags, feints, and quantum dashes.

3. **Weapon Arsenal (Interactive Cursors)**:
   - 🩴 **The Legendary Chappal**: Generational footwear with heavy blunt slap sound.
   - ⚡ **Neon Bug Zapper**: Electric crackle sparks on click.
   - 📰 **Rolled Daily News**: Crisp paper whack.
   - 🖐️ **Bare Hand**: Double clap impact.

4. **Irritation & Anti-Productivity Gauges**:
   - Real-time Whiff vs Swat counter.
   - Time Wasted & Productivity Lost ($) calculations.
   - Digital itch bite marks that appear on screen (soothed by virtual Calamine Lotion).
   - Official shareable **Rage Certificate** for certified swat clowns.
